HotTake turns a laptop into a party-game console: the laptop runs the host app and shows the game, and every player uses their phone as the controller through the browser. These docs are for people who want to go further than playing, whether that is understanding how it works, making a game, or helping build the app.

> Just want to play? The player guide is on [How to play](/how-to-play). Everything here is for developers.

## HotTake in one minute

- **One host, no cloud.** The desktop app runs a small web server on the laptop. Phones on the same Wi-Fi load the controller page from it, so there is no game server and no account.
- **Fast input.** Button presses travel over an unreliable WebRTC data channel (UDP), so a lost packet never holds up the next one. WebSocket is the automatic fallback.
- **Games are web pages.** Each game is a folder with a `manifest.json` and an `index.html`, running in a sandboxed frame on its own origin. Use plain canvas, Phaser, Pixi, three.js or WASM: the platform does not care.
- **A tiny SDK.** Games import one script to learn who joined, read each player's input, message phones and report results.
